# DESIGN Standard

This project adheres to the following UX/UI standards:

## Astryx Design System
- Utilizes `@astryxdesign/core` for consistent UI components and styling.
- Follows Astryx guidelines for typography, color palette, spacing, and iconography.

## PWA App Shell
- Implements an App Shell architecture for fast loading and native-like experience.
- Design considerations for offline capabilities and responsive layouts across various devices.
- Focus on touch-friendly interactions and accessibility for mobile users.
