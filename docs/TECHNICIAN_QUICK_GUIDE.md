# คู่มือฉบับย่อ — ช่าง (Technician)

คู่มือนี้สรุปงานที่ช่างทำบ่อย. อ่านรายละเอียดใน `docs/USER_GUIDE.md`. ตรวจสอบว่าสิทธิ์ของคุณคือ role 3 (Technician) — ถ้า UI แสดง "Operate" ให้ถือว่าเป็นสิทธิ์ช่าง (การเข้าถึงทำงานตามรหัสสิทธิ์, label เท่านั้นที่อาจต่าง).

## 1. เริ่มต้นใช้งาน
- เปิดเว็บที่ admin แจ้ง → หน้า Login
- เข้าด้วยบัญชีที่ได้รับ (ผู้ใช้/รหัสผ่าน)
- ลง PWA (ถ้าเครื่องนี้เป็น HTTPS): เบราว์เซอร์ → "Add to Home Screen" เพื่อใช้แบบแอป + เปิดใช้ offline ได้
- ออฟไลน์: ถ้าตอนนี้ไม่มีเน็ตให้ทำงานต่อได้ — ระบบบันทึกคิวไว้ แล้ววิ่ง sync ที่ศูนย์ซิงก์ (`/sync-center`) อัตโนมัติ

## 2. เป้า ดู/รับงานซ่อม (Work Order)
- เมนู **งานซ่อม** → ดูรายการการ์ด งานที่มอบให้คุณใช้ตัวกรอง "ของฉัน"
- กดเปิดงาน → ดูรายละเอียด: เครื่องจักร/ครุภัณฑ์, ปัญหา, รูปภาพ, ประวัติ
- **เปลี่ยนสถานะ** ผ่านปุ่ม: Start (เริ่ม) → Pause/Resume → Done (ทำเสร็จ) — ตามที่งานนั้นรับได้
- ถ้าเจออุปสรรค: เพิ่มบันทึก/อัปเดตในงานให้หัวหน้าเห็น

## 3. ภาพถ่าย & เอกสาร
- ถ่ายรูปเครื่อง/สาเหตุ/ของเสีย แล้วแนบกับงาน (รองรับ offline → sync ทีหลัง)
- ตำแหน่งสำคัญ: ถ่ายก่อน-หลัง เพื่อให้ verify ชัด

## 4. ตรวจเช็กลิสต์ / ตรวจสอบเครื่อง (PM & Inspection)
- เมนู **PM&AM** → รายการตรวจที่ถึงกำหนด → เปิดแบบฟอร์มตรวจ (checklist) → ผ่าน/ไม่ผ่านแต่ละข้อ + หมายเหตุ
- **ตรวจสอบเครื่องจักร (Inspection)** คล้ายกัน: ทำตาม checklist ให้ครบแล้วส่งผล
- รายการ PM ที่เลื่อนกำหนด (deferral) ต้องมีเหตุผล → หัวหน้าอนุมัติ

## 5. อะไหล่
- หน้าอะไหล่ใช้สต็อกจาก Sage 300 เป็นหลัก (stock ตัวจริง = Sage)
- ถ้าต้องเบิก/เปลี่ยนอะไหล่: สร้างคำขอเบิก (request) ในงาน → รออนุมัติ
- ตรวจสอบยอดผ่านหน้า colony/docs ตามที่สิทธิ์ให้

## 6. ช่วงไม่มีเน็ต (Offline Quick)
- ทำงานตามปกติ → เปิดหน้า /sync-center ดู "ค้างส่ง" → รอ sync automate; ถ้าค้างติดนาน/error → รายงาน admin (ดู docs/INCIDENT_RESPONSE.md §4)

## 7. เมื่อเสร็จงาน
- กรอกผลลัพธ์/สรุปให้ครบ + รูป → กด Done → งานเข้ารอหัวหน้าตรวจ (Verify)
- การตรวจ final เป็นของหัวหน้า — คุณไม่ต้อง "ปิด" งาน
