Quick User Guide — the five things you do every day

เริ่มต้นใช้งาน | Getting started
1

เปิดเว็บ / สแกน QR Code

เปิดเบราว์เซอร์มือถือหรือคอมพิวเตอร์ แล้วสแกน QR ด้านขวา หรือพิมพ์ลิงก์ที่ฝ่ายไอทีแจ้ง

2

เข้าสู่ระบบ

กรอก Username / Password ที่ได้รับ หรือกด "เข้าสู่ระบบด้วย LINE" — เมนูที่เห็นขึ้นกับบทบาทของคุณ

3

ติดตั้งเป็นแอป (PWA)

เมนูเบราว์เซอร์ → "Add to Home Screen" / "ติดตั้งแอป" เพื่อเปิดเร็วขึ้นและใช้งานได้แม้ไม่มีเน็ต

สแกนเพื่อเข้าใช้งาน
https://cmms-tpt.shares.zrok.io/
5 งานหลักที่ใช้บ่อย | Everyday tasks

1. แจ้งซ่อมเครื่องจักรReport a breakdown

  1. เมนู งานซ่อม / คำขอ → "สร้างคำขอ/แจ้งซ่อม"
  2. เลือกเครื่อง/ไลน์ที่พบ + อาการ + ความเร่งด่วน
  3. ถ่ายรูปจุดที่ผิดปกติ แล้วแนบ
  4. ส่ง → รออนุมัติ → กลายเป็นงานซ่อม (WO)
Operator / ทุกคนที่พบปัญหา

2. รับงานซ่อมWork on an assigned work order

  1. เมนู งานซ่อม → กรอง "ของฉัน"
  2. เปิดงาน ดูเครื่อง ปัญหา รูป และประวัติ
  3. กด Start → Pause/Resume ตามสถานการณ์
  4. แนบรูปก่อน–หลัง แล้วกด Done เพื่อส่งตรวจ
Technician

3. ตรวจ PM & AMComplete PM checklists

  1. เมนู PM&AM → รายการที่ถึงกำหนด
  2. เปิดแบบฟอร์มตรวจ (checklist)
  3. ทำเครื่องหมาย ผ่าน / ไม่ผ่าน + หมายเหตุ
  4. ส่งผล — เลื่อนกำหนดต้องมีเหตุผลและรออนุมัติ
Technician / ผู้รับผิดชอบเครื่อง

4. เบิกอะไหล่Request spare parts

  1. เปิดงานซ่อมที่กำลังทำ → สร้างคำขอเบิก
  2. ระบุรายการและจำนวนที่ต้องการ
  3. รออนุมัติก่อนจ่ายของ
  4. ยอดสต็อกจริงอ้างอิง Sage 300
Technician / Planner

5. สแกน QR ที่เครื่องจักรScan the asset QR

  1. เมนู สแกน → ส่อง QR ที่ติดเครื่อง
  2. เปิดประวัติซ่อม / PM / คู่มือของเครื่อง
  3. แจ้งซ่อมหรือเปิดงานได้ทันทีจากหน้านั้น
ทุกบทบาท

ตรวจรับและปิดงานVerify & close (Supervisor)

  1. เมนู Supervisor / คิวตรวจ
  2. ตรวจผลงาน + รูป + อะไหล่ที่ใช้
  3. ผ่าน → ปิดงาน / ไม่ผ่าน → ตีกลับพร้อมเหตุผล
Supervisor / หัวหน้างาน
ใครทำอะไร | Who does what
บทบาท / Role งานหลักในระบบ / Main responsibilities
Operator แจ้งซ่อมพร้อมรูป ติดตามสถานะใน "คำขอของฉัน" — ไม่ปิดงานเอง
Technician รับงานซ่อม อัปเดตสถานะ ตรวจ PM/AM เบิกอะไหล่ แนบหลักฐานรูป
Supervisor มอบหมายงาน อนุมัติเลื่อนกำหนด ตรวจรับและปิดงาน ดูคิวงานค้าง
Planner / Manager วางแผน PM งบประมาณ อะไหล่ รายงาน KPI และ Dashboard ผู้บริหาร
Admin จัดการผู้ใช้/สิทธิ์ ทรัพย์สิน แผน PM ตั้งค่าระบบ และ Audit Log

ข้อควรรู้ / Tips

  • ไม่มีสัญญาณ: ทำงานต่อได้ตามปกติ ระบบเก็บคิวไว้ แล้วเปิด /sync-center เพื่อซิงก์เมื่อกลับมาออนไลน์
  • รูปถ่ายคือหลักฐาน: ถ่ายก่อน–หลังทุกครั้ง เพื่อให้ตรวจรับและวิเคราะห์ปัญหาได้
  • สิทธิ์ตามบทบาท: ถ้าปุ่มที่ต้องการไม่แสดง ให้แจ้งหัวหน้าหรือ Admin — อย่าใช้บัญชีของผู้อื่น
  • แจ้งเตือน: PM ที่ถึงกำหนด ระบบส่งเตือนอัตโนมัติ (LINE / อีเมล / กระดิ่งในระบบ) ตามที่ตั้งไว้
