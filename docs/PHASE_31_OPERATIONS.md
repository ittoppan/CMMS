# PHASE 31 OPERATIONS — การใช้งานประจำวัน

> Phase 31 — คู่มือสำหรับผู้ใช้งาน/ผู้ดูแลระบบ (ไม่ใช่เอกสาร API)

## 1. บทบาทที่เกี่ยวข้อง

| บทบาท | ทำอะไรในหน้านี้ |
|---|---|
| ผู้จัดหาสัญญา / ผู้ดูแลสัญญา | เปิดผู้รับเหมา, บันทึกเอกสาร/สัญญา, ประเมินคุณสมบัติ |
| หัวหน้าชุด / ผู้ควบคุมงาน | assign งาน, ยิงงาน, ตรวจรับงาน, เดิน/verify มาตรการแก้ไข, เขียนรีวิว |
| ผู้อนุมัติ (admin) | เปลี่ยนสถานะผู้รับเหมา/บล็อก, ตัดสินคุณสมบัติ, **ผูก PTW** |
| ผู้บริหาร | ดูแดชบอร์ด, analytics, รายงาน 12 แบบ |

## 2. เปิดผู้รับเหมาใหม่ (`/contractors/create`)

1. กรอก **ชื่อบริษัท** (บังคับ, ห้ามซ้ำ) และ **เลขประจำตัวผู้เสียภาษี** (ห้ามซ้ำ)
2. เลือก **ผู้รับผิดชอบฝั่งเรา** (ควรระบุเสมอ — dashboard จะเตือนถ้าไม่มี)
3. เลือก **หมวดงาน** ที่ให้บริการ (จาก 15 หมวดที่เปิดใช้)
4. เพิ่ม **ผู้ติดต่อ** (เบอร์/ไลน์) — ใช้ส่งแจ้งเตือน
5. บันทึก → สถานะเริ่มต้น `draft` รหัสอัตโนมัติ `CON-2026-001`

> ระบบจะเตือนเรื่อง `draft` ที่ค้างเกิน 30 วัน และ `pending_qualification` เกิน 90 วัน

## 3. ประเมินคุณสมบัติ (`/contractors/[id]`)

1. อัปโหลดเอกสารให้ครบตามที่กำหนด — 4 ประเภทบังคับหมดอายุ:
   ประกัน, ใบรับรองความสามารถ, ใบอนุญาต, หนังสือความปลอดภัย (+ หลักฐานอบรมความปลอดภัย)
2. เพิ่ม **พนักงาน** และ **ใบรับรอง** ที่จำเป็นตามหมวดงาน
3. กด **เปิดรอบประเมิน** → ให้คะแนน 9 มิติ → **ส่งประเมิน**
4. ผู้อนุมัติตัดสิน: `ผ่าน` / `ผ่านมีเงื่อนไข` / `ไม่ผ่าน` + กำหนดวันหมดอายุ

> ทุกรอบประเมินเก็บเป็นแถวใหม่ (ประวัติครบ ไม่ถูกเขียนทับ)

## 4. ทะเบียนผู้รับเหมา (`/contractors`)

- KPI: active / qualified / รอประเมิน / ถูกบล็อก / เอกสารใกล้หมดอายุ
- ตัวกรอง: สถานะ, หมวดงาน, ผู้รับผิดชอบ, ค้นหาชื่อ/รหัส
- แถวที่ `qualified` เท่านั้นที่เลือกได้ตอน assign งาน

## 5. งานภายนอก (`/contractors/work`)

### 5.1 สร้างงาน (assign)
กรอก: ผู้รับเหมา, ชื่องาน, งานปกติ/asset, หมวดงาน, วันเริ่ม-จบ, ความสำคัญ
เลือก `ต้องใช้ใบอนุญาต (PTW)` ได้ถ้างานเสี่ยง

### 5.2 เดินสถานะ (หน้าเดียวกัน)

```
requested → contractor_selected → assigned → safety_review → permit_ready
   → work_started → work_completed → inspection → accepted → invoiced → closed
                                                     ↓ ถ้าไม่ผ่าน
                                                  rework → inspection
```

- **ถ้างานต้องใช้ PTW**: ระบบจะไม่ให้เข้า `work_started` จนกว่าจะผูก permit
  ที่ `approved`/`active` — ปุ่มจะแจ้งเตือนพร้อมลิงก์ไป `/safety/work_permit`
  (การผูก PTW เป็นสิทธิ์ `approve` → ต้องให้ผู้อนุมัติเป็นผู้กด)
- **งานที่เริ่มแล้วยกเลิกไม่ได้** — ต้องตรวจรับและปิดให้ครบ
- SLA คำนวณอัตโนมัติ (ตอบรับ 4 ชม. / เริ่มงาน 48 ชม. / เสร็จตามกำหนด / ฉุกเฉิน 1 ชม.)
  เกินกำหนด → แจ้งเตือนเจ้าของงาน

### 5.3 ตรวจรับงาน
เลือก `ผ่าน` / `ผ่านมีเงื่อนไข` / `ไม่ผ่าน` + ช่องข้อบกพร่อง
- ไม่ผ่าน → เข้าสถานะ `rework` พร้อมกำหนดกำหนดแก้ไข
- ทุกครั้งที่ตรวจถูกเก็บเป็นรอบ (round) แยก

## 6. ติดตามผลงาน

- **Performance** (`/contractors/[id]`): งานที่ปิดจริงในช่วงเวลาที่กำหนด
  - ถ้างานน้อยกว่า 3 รายการ ระบบจะขึ้น `ข้อมูลไม่เพียงพอ` **ไม่ใช่ 0 คะแนน**
- **Cost summary**: อ่านค่าใช้จ่ายจริงจากงานปกติ ถ้ายังไม่มีจะขึ้น
  `external_cost_not_recorded` — ระบบ **ไม่กุค่าใช้จ่ายขึ้นมาเอง**
- **รีวิวผลงาน**: รายเดือน/ไตรมาส/ครึ่งปี/ปี

## 7. มาตรการแก้ไข (Corrective Actions)

```
เปิดปัญหา → ทำรายการแก้ไข → completed → ผู้อนุมัติ verify → verified
```
ระบบ**บังคับให้ verify ก่อนปิด** — ป้องกันการปิดงานโดยไม่มีหลักฐาน

## 8. งานประจำ (Routine)

| ความถี่ | ทำอะไร |
|---|---|
| ทุกวัน | เช็คแดชบอร์ด: เอกสาร/ใบรับรองใกล้หมดอายุ, SLA breach, งานค้าง |
| ทุกสัปดาห์ | ประเมินผู้รับเหมาใหม่ที่รออยู่ (`pending_qualification`) |
| ทุกเดือน | รีวิวผลงานผู้รับเหมา (performance) + ตรวจ corrective actions ค้าง |
| ทุกไตรมาส | ตรวจสัญญาใกล้หมดอายุ + ทบทวนรายชื่อ `blocked` (`block_review_date`) |
| ทุกปี | archive `contractor_activity` เก่า, ล้างเอกสาร `archived` เกินกำหนด |

## 9. ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| เข้า `work_started` ไม่ได้ | งานต้องใช้ PTW แต่ยังไม่ผูก permit → กดปุ่มแจ้งเตือนเพื่อไปออก permit |
| เลือกผู้รับเหมาใน assign ไม่ได้ | สถานะไม่ถึง `qualified`/`conditional` หรือ `is_active=0` |
| บันทึกผู้รับเหมาไม่ได้ | `company_name` หรือ `tax_id` ซ้ำ (ข้อความแจ้ง 409) |
| Performance ขึ้น `ข้อมูลไม่เพียงพอ` | งานที่ปิดยังน้อยกว่า `contractor_score_min_jobs` (ค่าเริ่มต้น 3) |
| ค่าใช้จ่ายเป็น 0 | ยังไม่ได้บันทึก `cost_outsource` ของงานปกติ — ระบบไม่เดาให้ |
| เมนูไม่โผล่ | ยังไม่มีสิทธิ์ `contractor/view` หรือยังไม่ grant เมนู (`menu_permissions`) |
