# 1. ระบบงานซ่อม

## 1.1 การแจ้งซ่อม
เข้าที่ **เมนู Repair: แจ้งซ่อม** (`/repair/request`) หรือสแกน QR ที่ตัวเครื่องไปที่ `/scan` แล้วกด "แจ้งซ่อม"
1. เลือก **เครื่องจักร / เครื่องมือ*** — ค้นหาได้จากชื่อเครื่อง หรือเลข QR Code
2. ระบุ **ลักษณะอาการเสีย*** / ความด่วน (ปกติ/ด่วน/CRITICAL) และช่องอื่นตามแบบฟอร์ม (ประเภทใบงาน, เกี่ยวกับความปลอดภัย, Product Lot No. ฯลฯ)
3. แนบ **ภาพอาการเสีย** / คลิปวิดีโอ (ถ้ามี)
4. กด **ยืนยัน** → หน้าจอ "แจ้งซ่อมสำเร็จ" → **ปิด**
5. ระบบแจ้งเตือนอัตโนมัติ: LINE กลุ่มช่าง (การ์ดสีแดง + รูป) → หัวหน้าจัดการมอบหมาย → ช่างที่รับมอบหมายได้ LINE Push, อีเมลแจ้งผู้เกี่ยวข้อง
> งานด่วนจะส่ง LINE ทันทีพร้อมปุ่มดูรายละเอียด

## 1.2 การแจกงานซ่อม (สิทธิ์: หัวหน้า/วิศวกร)
**เมนู Repair: แจกงานซ่อม** (`/repair/assign`)
1. กรองได้ตามต้องการ: สถานะ (รอมอบหมาย / มอบหมายแล้ว / กำลังซ่อม), ค้นหาช่าง, เลขใบงาน
2. แถบสรุปด้านบน: `รอมอบหมาย / มอบหมายแล้ว / กำลังซ่อม`
3. กด **มอบหมายงาน** → กล่อง "มอบหมายงานซ่อม"
   - เลือก **ช่างผู้รับผิดชอบ*** (+เพิ่มทีมช่างร่วมงานได้)
   - กด **บันทึก** → ช่างเห็นงานใน "งานของฉัน" ทันที **และได้รับแจ้งเตือน LINE** ("งานถูกมอบหมายให้คุณ")
4. กด **ปิด** เมื่อหน้าจอยืนยัน

## 1.3 การเปลี่ยนผู้รับผิดชอบงานซ่อม
- ยังอยู่ที่ **เมนูแจกงานซ่อม** → ใบงานที่มอบหมายแล้วมีปุ่ม **เปลี่ยนช่าง** → เลือกช่างใหม่ (+ทีม) → **บันทึก**
- เฉพาะผู้มีสิทธิ์มอบหมายงานซ่อมเท่านั้น

## 1.4 งานซ่อมของฉัน (ช่าง)
**เมนู Repair: งานของฉัน** (`/repair/my_tasks`) แบ่งเป็น 3 แท็บ:
- **งานใหม่** — งานที่มอบหมายมา รายละเอียด: เครื่องจักร+QR, อาการเสีย, ผู้แจ้ง, สถานที่
  - ปุ่ม **รับทราบ** → ระบบแจ้งผู้มอบหมาย + ผู้แจ้งทาง LINE ว่าช่างรับงานแล้ว (กดแล้วกดอีกไม่ได้)
  - ปุ่ม **เริ่มซ่อม** → ย้ายงานไปแท็บ "กำลังซ่อม" + LINE แจ้งผู้เกี่ยวข้อง
  - ปุ่ม **ไปทำ PM** → เปิดเช็คชีต PM ของเครื่องนั้น (ถ้างานเป็นงาน PM)
- **กำลังซ่อม** — งานที่เริ่มซ่อมแล้ว
  - ระบุ **เสร็จวันที่** = วันที่คาดว่าจะซ่อมเสร็จ (แจ้งผู้แจ้งซ่อม)
  - เมื่อเบิกอะไหล่ รายการนี้มีสถานะแทรก "รออะไหล่" (Waiting parts)
- **ซ่อมเสร็จแล้ว** — งานที่ปิดเรียบร้อย

**ปิดงาน (Finish Task):** กด **ดูรายละเอียดปิดงาน** → กรอก
1. แนบรูปภาพหลังซ่อม
2. **กลุ่มอาการเสีย (Failure Code)** — เลือกจากที่ตั้งค่าไว้
3. **กลุ่มงานซ่อม (Repair Code)** — เลือกจากที่ตั้งค่าไว้
4. **Root Cause** (สาเหตุ) — พิมพ์วิเคราะห์เอง
5. **Solution** (วิธีแก้ไข) — พิมพ์เอง
6. กด **บันทึก** → ปิดงาน สำเร็จ (ระบบนับ Downtime/ค่าซ่อมเข้า Dashboard)

## 1.5 การติดตามงานซ่อม (ผู้แจ้งซ่อม)
**เมนู Repair: ติดตามงาน** (`/repair/tracking`)
- ดูสถานะใบงานของเรา: **รอมอบหมาย → มอบหมายแล้ว → ช่างรับงาน → กำลังซ่อม → ซ่อมเสร็จ → เรียบร้อย/รอประเมิน**

## 1.6 การประเมินงานซ่อม
- งานที่ช่างปิดแล้ว จะมีปุ่ม **ประเมิน** → ดูใบแจ้งซ่อม → ให้คะแนนดาว + ความเห็น → **บันทึก**

## 1.7 ประวัติงานซ่อม
**เมนู Repair: ประวัติงานซ่อม** (`/repair/history`)
- ตัวกรอง: ช่วงวันที่ / เครื่องมือ (ชื่อ-รหัส QR) / แผนก / ช่าง / ประเภทใบงาน / แสดงเฉพาะงานถูกปฏิเสธ
- ดูใบแจ้งซ่อมละเอียด, **พิมพ์** ใบงานได้

# 2. ระบบงาน PM&AM

## 2.1 เช็คชีต PM/AM บนมือถือ (ทำได้เฉพาะวันครบกำหนด)
> **กฎระบบ: ทำเช็คชีตได้เฉพาะวัน due date ของแผนนั้นพอดี** — วันอื่นรายการจะไม่ขึ้น + แจ้งเหตุ และระบบกันฝั่งเซิร์ฟเวอร์ (ส่งผ่าน offline ก็โดนกัน)

เข้าทางไหนก็ได้:
- **สแกน QR เครื่อง** → `/scan` → "ทำ PM" → ระบบเลือกแผนที่ครบกำหนดวันนี้ให้อัตโนมัติ
- **เมนูงานของฉัน** → งาน PM → "ไปทำ PM"
- **เมนู เช็คชีต** (`/pm_am/checksheet`)

ขั้นตอน:
1. เลือกแผนที่ครบกำหนดวันนี้ (ดรอปดาวน์ขึ้นเฉพาะแผน due วันนี้)
2. ตรวจทีละข้อ: **ผ่าน/ไม่ผ่าน** หรือ **บันทึกค่า** (เช่น อุณหภูมิมอเตอร์) + หมายเหตุ
3. กด **บันทึกผลการทำ PM** → ลงนามยืนยัน 2 ฝ่าย: **ผู้ตรวจเช็ค + ผู้ควบคุมเครื่อง** (เซ็นนิ้วบนจอ)
4. บันทึกแล้วสถานะเป็น Completed → **ส่งออก PDF (F-EN-02 แบบ ISO)** ได้
> Offline: เก็บ snapshot + คิวส่งงาน — ตรวจ/เซ็นได้แม้ไม่มีเน็ต แล้วกด "ส่งงานค้างทั้งหมด" เมื่อกลับมามีสัญญาณ

## 2.2 การสร้างเช็คชีท / แผน PM&AM
**เมนู PM: สร้างแผน** (`/pm_am/create`)
- ระบุ **เครื่องจักร/อุปกรณ์**, **ประเภท (PM/AM)**, **ความถี่** (รายวัน/สัปดาห์/เดือน/ไตรมาส/ปี), **วันที่เริ่ม/ครบกำหนด**, ผู้รับผิดชอบ/ทีม
- รายการตรวจสอบ (Checklist) ตามขั้นตอน + บันทึกค่าได้
- **เร่งสุ่มทีละหลายเครื่อง**: `/pm_am/batch_schedule` (สร้างแผนแบบกลุ่ม / ตามรอบ)
- หลังปิดงานหนึ่งรอบ ระบบ**สร้างรอบถัดไปอัตโนมัติ**ตามความถี่

## 2.3 ปฏิทิน PM&AM
**เมนู PM: ปฏิทิน** (`/pm_am/calendar`)
- ดูงานตามวัน/เดือน → กดงาน → **เปิดเช็คชีต**

## 2.4 การเลื่อนกำหนด PM (Deferral)
- งานที่ค้างแล้วแน่ใจว่าต้องเลื่อน → ปุ่ม **ขอเลื่อน** → ระบุวันใหม่ + เหตุผล
- ระบบ **ส่ง LINE หัวหน้า/แอดมิน** → กด **✅ อนุมัติ / ❌ ไม่อนุมัติ** ในแชทได้เลย (Postback) → ช่างแจ้งผล

## 2.5 ประวัติ / ผลงาน PM
- ดูผลย้อนหลัง: การตรวจ, ค่าที่วัดได้, ผ่าน/ไม่ผ่าน, ลายเซ็น (หน้าแผน PM → ดูผล)

# 3. ระบบงานสอบเทียบ
**เมนู การสอบเทียบ** (`/calibration`)
- รายการเครื่องมือ/อุปกรณ์ + สถานะ: ปีถัดไป (กำหนดล่วงหน้า), **กำหนดสอบเทียบ**, **หมดอายุ/เลยกำหนด** (สีแจ้ง)
- **เพิ่มเครื่องมือ / แผนสอบเทียบ** (`/calibration/create`): กำหนดรอบ (เช่น ทุก 12 เดือน), ผู้ให้บริการ (ซัพพลายเออร์), เลขใบรับรอง (Certificate No.)
- **แก้ไขประวัติสอบเทียบ** (`/calibration/edit`): กรอก วันที่สอบเทียบ / เลขที่ใบรับรอง / ค่าใช้จ่าย / ผล — เก็บใบเซอร์ไว้ดูย้อนหลัง
- ปฏิทิน/รายงานแสดงค่าบริการสอบเทียบรวมเพื่อวางงบประมาณรอบหน้า

# 4. ระบบงานอะไหล่

## 4.1 สต็อกอะไหล่ / ยอดคงเหลือ
**เมนู สต็อกอะไหล่** (`/spare_parts`)
- แท็บ: **ทั้งหมด / หมดคลัง**, KPI: จำนวนรายการ, หมดคลัง, มูลค่าคลังรวม
- แต่ละรายการ: รหัส, ชื่อ, คงเหลือ, หน่วย, Min/Max (ถ้าต่ำกว่า Min → แจ้งเตือน LINE), ราคา, ซัพพลายเออร์

## 4.2 เพิ่มรายการอะไหล่ / Master Spare Part
- `/spare_parts/create` (+แก้ไข `/spare_parts/edit`)
- ฟิลด์: รหัส (ห้ามซ้ำ), ชื่อ (ห้ามซ้ำ), ประเภท (อะไหล่/วัสดุสิ้นเปลือง), Min/Max, สเปค, หน่วยนับ, ราคาต่อหน่วย, ซัพพลายเออร์, ระยะเวลาจัดซื้อ (วัน), ไลน์การผลิต, ยี่ห้อ

## 4.3 รับอะไหล่เข้าคลังตาม PO
- **เมนู Sage PO / รับเข้าคลัง** (`/spare_parts/sage_po`): กรอกเลข PO → เลือกรายการอะไหล่ + จำนวน → **ยืนยันการรับเข้าคลัง**
- **นับสต็อก (Stock take)**: `/spare_parts/stock_take`
- ซิงก์ข้อมูล/รับเข้าจาก Sage 300: `/spare_parts/sage_sync`

## 4.4 ศูนย์เบิก-จ่ายอะไหล่
**เมนู ศูนย์เบิก-จ่าย** (`/spare_parts/issue_center`)
1. เลือกใบงานซ่อม / ผู้เบิก-รับผิดชอบ
2. เพิ่มรายการอะไหล่เข้าใบเบิก (หลายรายการ) — ระบบเช็คยอดคงเหลือ ถ้าไม่พอจะแจ้ง
3. กด **ยืนยันการเบิก-จ่าย**
> การเบิกจากใบงานซ่อม จะส่งคำขออนุมัติไปผู้อนุมัติ (ดูข้อ 4.5)

## 4.5 อนุมัติใบเบิกอะไหล่ (LINE + Email + ปุ่มกด)
เมื่อช่างขอเบิก ระบบส่งคำขอไปยัง **ผู้อนุมัติ** ทั้ง 2 ช่องพร้อมกัน:
- **LINE**: การ์ด "🧰 ขอเบิกอะไหล่ #... รออนุมัติ" + ปุ่ม **✅ อนุมัติการเบิก / ❌ ไม่อนุมัติ** — แตะในแชทได้เลย (บันทึกชื่อผู้พิจารณา+เวลา)
- **Email**: อีเมลถึงผู้อนุมัติพร้อมปุ่ม **อนุมัติ / ไม่อนุมัติ** (ลิงก์ 1-click ไม่ต้องล็อกอินซ้ำ)
- **ศูนย์อนุมัติรวม** (`/approval`): ดูคำขอค้างทั้งหมดที่อนุมัติได้
ผลการอนุมัติ/ไม่อนุมัติ → LINE แจ้งช่างผู้ขอทันที; ผู้อนุมัติลำดับต่อ (Store) ตรวจยอดคงเหลือแล้วปิดใบเบิก

## 4.6 การวิเคราะห์ & แจ้งเตือน
- **Optimize คลัง** (`/spare_parts/optimization`): AI วิเคราะห์ Reorder Point, Class A/B/C, อะไหล่ค้างคลัง (Dead stock)
- อะไหล่ต่ำกว่า Min → **LINE แจ้งเตือน** (เทมเพลต `line_tpl_low_stock`)

# 6. QR Code & การสแกน
- **ดาวน์โหลด QR**: `/qr-sheet` — เลือกช่วงหรือสถานที่ตั้ง → export ไปติดสติกเกอร์ที่เครื่อง (กลุ่มละ ≤500)

# 13. LINE โมบายบริดจ์ (พิเศษของระบบเรา)

## 13.1 ลงทะเบียนผูกบัญชี LINE
หน้า **/register** (ปุ่มใน Rich Menu):
1. กด **ล็อกอินด้วย LINE** (หรือเปิดผ่านหน้า LIFF ของ /register → ได้ LINE ID อัตโนมัติ)
2. กรอกเลขพนักงาน → **ผูกบัญชี** → หน้า "ผูกบัญชีสำเร็จ" + LINE ยืนยันเขียวในแชท
3. ผูกแล้ว → งานที่แจ้ง/รับ มีชื่อคุณอัตโนมัติ และรับ Push ถึงตัว

## 13.2 Rich Menu
3 ปุ่มแนะนำ: **แจ้งซ่อม** (`/scan`), **ลงทะเบียนผูก LINE** (`/register`), **หน้าแรก** (`/`)

## 13.3 การแจ้งเตือนผ่าน LINE (Push)
เหตุการณ์หลัก: งานซ่อมถูกมอบหมาย / ช่างรับ-เริ่ม-ปิดงาน / ขอเบิกอะไหล่ + อนุมัติ / PM เกินกำหนด / ขอเลื่อน PM / อะไหล่ต่ำสต็อก / ผูกบัญชีสำเร็จ — ทุกการ์ดปรับได้ใน `ตั้งค่า > การแจ้งเตือน`

# ข้อแนะนำเพิ่มเติม (แนะนำเร็วๆ นี้)
1. **สร้าง LIFF App ของหน้า /register** ใน LINE Developers (endpoint = `https://ommatophorous-robert-fortifyingly.ngrok-free.app/register`) → วาง ID ใน `ตั้งค่า > การแจ้งเตือน` — ลดขั้นตอนล็อกอิน 2 คลิก
2. **อัปเดต `TELEGRAM_BOT_TOKEN` ใน .env** — token เดิมถูก revoke (LINE push ทำงานปกติ แต่แจ้งแอดมินทาง Telegram ยังไม่ได้)
3. **ตั้ง Rich Menu** จริง + เพิ่ม **Deep-link ไปหน้าใบงาน** ในทุกการ์ด (เช่น ปุ่มการ์ด "มอบหมายงาน" → ชี้ `/repair/view?id=`)
4. **ทดสอบ e2e บน LINE**: ผูก → แจ้งซ่อม → มอบหมาย → ช่างรับ/เริ่ม/ปิด → เบิกอะไหล่ → ผู้อนุมัติกดปุ่ม LINE/Email
5. ฟีเจอร์ที่เพิ่มได้ตามโมเดลคู่มือต้นฉบับ: **สอบเทียบ ปฏิทิน/PO/ติดตามงานสอบเทียบ** และ **ยอดคงเหลือ/คืนซากอะไหล่** แยกเมนู (ตอนนี้รวมอยู่ในการสอบเทียบ/สต็อก)
