# คู่มือฉบับย่อ — ผู้ควบคุมเครื่อง (Operator)

คู่มือนี้สำหรับผู้ใช้ role 4 (Operator). สิ่งที่คุณทำหลักๆ = แจ้งปัญหาเครื่อง และติดตามสถานะ.
รายละเอียดเต็มใน `docs/USER_GUIDE.md`.

## 1. เริ่มต้น
- เปิดเว็บตามที่ฝ่ายไอทีแจ้ง → Login ด้วยผู้ใช้/รหัสของคุณ
- แนะนำ: PWA (ถ้าใช้ HTTPS) → เพิ่มหน้าเว็บเข้าโฮมสกรีนบนมือถือเพื่อเข้าเร็ว

## 2. แจ้งปัญหาเครื่อง (Maintenance Request)
- เมนู **งานซ่อม/คำขอ** → ปุ่ม "สร้างคำขอ/แจ้งซ่อม"
- กรอก: เครื่อง/ไลน์ที่พบ, อาการ, ความเร่งด่วน → **ถ่ายรูปจุดที่ผิดปกติ** → ส่ง
- คำขอจะเป็น "รออนุมัติ" → แล้วกลายเป็นงานซ่อม (WO) เมื่อหัวหน้า/แผนกอนุมัติ

## 3. ดูสถานะ
- การ์ดงาน: รออนุมัติ → กำหนดช่าง → ระหว่างซ่อม → รอตรวจ → ปิด
- ติดตามในมุมมอง "คำขอของฉัน" (ตามสิทธิ์)
- เมื่อช่างปิดแล้ว ระบบจะแจ้งผลผ่านช่องทางที่ตั้ง (LINE/อีเมล) ถ้าเปิดไว้

## 4. ภาพถ่าย
- ถ่ายรูปเหตุตอนแจ้งชัดๆ (เครื่อง/จุดเสีย) เพื่อให้ช่างประเมินก่อนไปดู

## 5. ออฟไลน์
- เขียนคำขอได้ตอนไม่มีเน็ต → บันทึกคิว → ส่งทันทีที่กลับมาออนไลน์ (ดู /sync-center) — เขียนได้ตามปกติแม้สัญญาณไม่ดี

## 6. สิ่งที่ไม่ควรทำ
- อย่ากด "ปิดงานซ่อม" หรือทำรายการขั้นสูงกว่าสิทธิ์ (สิทธิ์ของคุณเป็น role 4 เท่านั้น)
- ถ้าพบงานค้าง/สถานะผิด ให้แจ้งหัวหน้า/admin (ดู docs/INCIDENT_RESPONSE.md §4)
